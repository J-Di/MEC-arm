Design in progress

Motor drive

The ESC power stage will drive a brushless joint motor while the control loop regulates torque and position.

Architecture

Each joint is planned to use a brushless motor with field oriented control. The ESC should remain compact enough to mount behind its motor and generic enough to use on several joints.

What to add as the board develops

Document the selected gate driver and MOSFETs, DC bus and phase connections, PWM strategy, switching frequency, current and thermal ratings, PCB layout, and measured switching behavior. Mark measured results separately from design targets.

This project is ongoing. Design goals, planned work, and measured results will be distinguished as the pages grow.
