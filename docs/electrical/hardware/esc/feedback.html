Design in progress

Sensing & feedback

The joint controller needs motor position feedback and electrical measurements for smooth low speed control.

Magnetic position feedback

The current concept puts a magnetic encoder at the motor input shaft, with the ESC mounted immediately behind the motor. This avoids a separate external motor-shaft encoder coupling.

Measurements to document

As the design is finalized, record encoder selection and alignment, phase-current sensing, bus-voltage sensing, temperature monitoring, calibration, filtering, and validation data. The exact circuits are not specified in the project README yet.

This project is ongoing. Design goals, planned work, and measured results will be distinguished as the pages grow.
