Purpose

The arm is planned around a 6S LiPo battery and seven distributed motor controllers. A central board will distribute and convert power as needed and consolidate system connections.

Open design work

The README has not settled the board's detailed power rails, current budget, connectors, or host interface. The pages below are places to record those decisions and their test results.

This project is ongoing. Design goals, planned work, and measured results will be distinguished as the pages grow.
