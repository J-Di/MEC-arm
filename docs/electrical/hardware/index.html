Electrical hardware

Two board families form the planned electrical backbone: one controller behind each motor and one central power and coordination board.

Joint-level electronics

Each ESC is intended to fit behind a motor so it can read the motor-shaft magnetic encoder without a separate external encoder coupling. The same controller design is intended to serve different joints.

Central electronics

The separate board is planned to distribute and convert power, coordinate connections, and provide a host-to-arm interface. Its final architecture remains under design.

This project is ongoing. Design goals, planned work, and measured results will be distinguished as the pages grow.
