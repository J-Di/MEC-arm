Electrical

The arm's electrical system powers seven brushless motors, closes the loop at each joint, and connects the joints to a central host.

System approach

We are designing a compact ESC for each motor and a separate power distribution and coordination board. The intended network uses CAN bus, with a Raspberry Pi as the host.

What this section covers

Start with the hardware pages for board design and subsystems, or move to firmware for control and communication. Component choices and test results can be added to each page as the design matures.

This project is ongoing. Design goals, planned work, and measured results will be distinguished as the pages grow.
